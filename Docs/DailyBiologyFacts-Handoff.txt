Daily Biology Facts · CellLab

Project integration
The existing app targets iOS 26.2. There was no prior widget, Settings screen,
URL scheme, or notification delegate. CellLabDailyFactsWidget is a WidgetKit
extension, embedded through an app target dependency and Embed App Extensions.
It also targets iOS 26.2 and supports small and medium Home Screen widgets.
No App Group, APNs entitlement, account, server, or network request is needed.

Content
CellLab/daily-facts.json is the single canonical source file. The app's existing
synchronized group bundles it; the widget resource phase references that same
file. Its original bytes, 69 stable IDs, facts, and source links are preserved.

Date selection
Gregorian civil-date anchor: 2024-01-01, fact-001. Convert the current instant to
the device's local Gregorian year/month/day, count Gregorian days from the
anchor, and normalize modulo 69 over fact-001 through fact-069. Calendar-day
arithmetic, rather than elapsed seconds, handles DST and year boundaries.
App, widget, and alerts all use this same selector. Widget timelines contain
today plus seven upcoming local midnights, with an atEnd refresh request.
WidgetKit controls when a refresh is actually granted.

Navigation
Widgets use celllab://home to open the main CellLab screen, resetting any lesson,
game, or Settings navigation. Cached celllab://fact/fact-001 style links also
return home, so existing widgets and alerts continue working. Alerts retain their
stable fact ID metadata and displayed text, but tapping them returns to CellLab.
The separate Biology Fact page has been removed at the user's request. Optional
reading and tappable sources now expand inline under Settings > Today’s Fact;
there is no fact banner on the main home page.

Reminders
Daily fact reminder starts OFF. Only the explicit Settings toggle requests
notification permission. Denial leaves the switch off and offers Open Settings.
The default local time is 9 AM; the time picker changes and persists it.
Daily alerts contain widgetText plus the stable fact ID and deep link.
Reconciliation occurs at launch, foreground, local day changes, significant time
changes, time-zone changes, and reminder setting changes. Mutations are serialized
and newer settings supersede stale scheduling work.

CellLab schedules up to 30 future dated alerts, within a conservative 64-request
pending limit after accounting for other features. Only identifiers beginning
celllab.daily-fact. are replaced or removed. No repeating generic daily alert is
used: each queued date has its own fact. Past times are skipped, and a reminder
in a spring DST gap moves to the next valid time preserving minutes; a repeated
fall-back time uses its first occurrence.

IMPORTANT: If the app stays unopened beyond its queued window, daily reminders
may pause. Open CellLab to replenish them. This is also explained in Settings.

Add the widget on an iPhone
Install and open CellLab once. Touch and hold an empty area on the Home Screen,
choose Edit > Add Widget, find CellLab / Daily Biology Fact, choose small or
medium, tap Add Widget, then Done. Tap the widget to open the main CellLab screen.

Device verification
Simulator builds/tests cannot establish real-device notification delivery timing,
Focus/Scheduled Summary behavior, or the system's actual midnight widget reload
budget. On your signed device, check both widget sizes and source links, allow
the optional reminder, select a convenient future time, background the app, and
tap the delivered alert. Check time-zone/DST behavior when practical. Revoke
notification permission in iOS Settings and return to CellLab to confirm it
reflects the change. Disable the reminder to stop this feature's queued alerts.
Do not expect alerts after the finite window without reopening the app.
