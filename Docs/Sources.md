# Sources

Reactome is a curated, peer-reviewed pathway database. The supplied database records use CC0-1.0 data terms and link to Reactome's license page. Reactome illustrations have a separate CC BY 4.0 license; CellLab does not include or claim CC0 reuse of those illustrations.

Each catalog source keeps its provider, HTTPS URL, optional accession, license identifier and URL, access date, and verification note. The planning assistant accessed the three Reactome records on 2026-11-11. This is recorded transparently and is not an independent scientific review by the implementing assistant.

Evidence records connect concise claims to sources. Only the claims marked source-checked have the explicit mappings supplied for this milestone. Other claims remain pending. The user-provided biology overview is retained as draft background, and the lesson brief describes product scope; neither is independent scientific evidence. Source metadata and evidence are bundled and readable offline; only opening an external link needs a network connection.
